# report-notes/

Optional hand-written cards for the Test Execution Report. Each file is picked up only if it exists:

- `human_action_items.json` → "Human Action Required"
- `investigation_items.json` → "Investigation / Evidence-Gathering Results"
- `gaps.json` → "Open Gaps / Limitations"
- `sheet_links.json` → links from test case IDs to the test case sheet
